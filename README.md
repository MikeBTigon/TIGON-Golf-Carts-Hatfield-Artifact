# TIGON Golf Carts — Hatfield, PA

A single-page, sourced overview of TIGON Golf Carts' Hatfield, Pennsylvania dealership, with citations linking back to [tigongolfcarts.com/hatfield](https://tigongolfcarts.com/hatfield).

**Live site:** https://mikebtigon.github.io/TIGON-Golf-Carts-Hatfield-Artifact/

## Publishing with GitHub Pages

The site is a static `index.html` at the repository root. `.github/workflows/pages.yml` deploys it to GitHub Pages on every push to `claude/stoic-knuth-42o6in`.

One-time setup: in **Settings → Pages → Build and deployment**, set **Source** to **GitHub Actions**.
